# 文献采集规则

1. 期刊主页仅用于确认范围、标题、ISSN 和公开入口，不作为批量受限全文来源。
2. 元数据优先通过公开接口获取；当前构建器实现 Crossref 与 PubMed E-utilities，OpenAlex 与 PMC OA 属于后续可选扩展。遵守 User-Agent、联系信息、速率限制、重试与退避规则。
3. 不绕过登录、付费墙、验证码、robots 或访问控制。SAGE/Taylor & Francis 的受限正文不得打包。
4. 只有许可证明确允许再分发的开放全文才可进入发行包；否则仅保存题录、摘要（若接口允许）、标识符和落地页链接。
5. 每条记录保存来源、源标识、抓取时间、许可和 URL；以 DOI、PMID、OpenAlex ID 去重。
6. 采集失败要写入 `crawl_runs`，不得静默用旧数据冒充本次成功。
7. 增量更新保留已有记录并更新可验证字段；不得因一次上游失败清空数据库。
